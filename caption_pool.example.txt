# 자막 후보 문구 — 업종에 맞게 바꿔 쓰는 파일
#
# 이 파일을 caption_pool.txt 라는 이름으로 복사한 뒤 고치면 적용된다.
#   복사:  copy caption_pool.example.txt caption_pool.txt
#
# 형식:  유형 = 문구 | 문구 | 문구
# 유형:  result   만들어진 것·완성품·화면
#        wide     전체가 보이는 장면
#        practice 뭔가 하고 있는 장면
#        collab   두세 명이 같이 있는 장면
#        tool     도구·장비·재료를 쓰는 장면
#        closeup  얼굴·손이 크게 찍힌 장면
#        other    그 밖
#        ending   마지막 컷
#
# 적어둔 유형만 바뀐다. 안 적으면 기본값(수업 현장 말투)이 그대로 쓰인다.
# 자막을 컷마다 직접 쓰고 싶으면 사진 폴더에 captions.txt 를 두면 된다.
#
# --- 아래는 카페 예시다. 지우고 본인 업종 말투로 바꿔라. ---

result = 오늘 나온 잔^^ | 완성! | 이렇게 나왔어요~
wide = 오픈 준비 끝~ | 자리 다 찼습니다^^
practice = 손이 바빠지는 시간~~~ | 여기서부터 조용해짐
collab = 둘이 붙어서 맛보는 중^^ | 같이 하니까 금방 됨!
tool = 오늘 원두 이걸로~ | 이게 진짜 되네~~~
closeup = 이 색이 다 했다^^ | 진지함 그 자체~~~
other = 이런 것도 합니다~ | 계속 이어집니다~~~
ending = 다음에 또 오세요^^ | 오늘 제일 잘 나간 메뉴!
