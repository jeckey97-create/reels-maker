# 키워드 → 해시태그 사전 — 업종에 맞게 바꿔 쓰는 파일
#
# 이 파일을 tag_rules.txt 라는 이름으로 복사한 뒤 고치면 적용된다.
#   복사:  copy tag_rules.example.txt tag_rules.txt
#
# 폴더 이름·자막·info.txt 에 왼쪽 키워드가 들어 있으면 오른쪽 태그가 붙는다.
# 이 파일을 두면 내장 사전(교육·강의용)은 **쓰이지 않는다.**
#
# 형식:  키워드 = #태그 #태그
#
# --- 아래는 카페 예시다. 지우고 본인 업종으로 바꿔라. ---

원두 = #스페셜티커피 #홈카페
드립 = #핸드드립 #커피스타그램
디저트 = #수제디저트 #카페디저트
신메뉴 = #신메뉴 #카페추천
